# Contributing

This repo contains 2 things:

* the code for [nhsapp-frontend](https://design-system.nhsapp.service.nhs.uk/get-started/nhsapp-frontend/) – in `/src`
* the content for the [NHS App design system website](https://design-system.nhsapp.service.nhs.uk) - in `/docs`

Contributions are welcome for both!

Read the [Community section](https://design-system.nhsapp.service.nhs.uk/community/) of the NHS App design website for guidance on how to contribute.
