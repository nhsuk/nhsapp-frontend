| Name                    | Type             | Required    | Description                                                                                                                                                                |
| ----------------------- | ---------------- | ----------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| heading                 | string or object | conditional | Card heading. Pass a string or an object with `text`, `html`, `level`, `classes`, `size` or `id`. Renders as a link, heading or paragraph.                                 |
| heading.text            | string           | conditional | Plain text heading. Ignored if `heading.html` is given.                                                                                                                    |
| heading.html            | string           | conditional | HTML heading (allows markup). Overrides `heading.text`.                                                                                                                    |
| heading.level           | number           | conditional | Heading level (2–6) used only when there is no `href`. If not set (and no `href`) the heading is a paragraph.                                                              |
| heading.classes         | string           | no          | Classes for the heading element.                                                                                                                                           |
| heading.size            | string           | no          | Size of the heading: `xxs`, `xs`, `s`, `m`, `l` or `xl`. Adds the matching `nhsuk-heading-*` class.                                                                        |
| heading.id              | string           | no          | ID for the heading element.                                                                                                                                                |
| headingHtml             | string           | conditional | Deprecated. Use `heading.html` instead. Will be removed in v6.0.0.                                                                                                         |
| title                   | string or object | conditional | Deprecated. Use `heading` instead. Will be removed in v6.0.0.                                                                                                              |
| titleHtml               | string           | conditional | Deprecated. Use `heading.html` instead. Will be removed in v6.0.0.                                                                                                         |
| href                    | string           | conditional | Makes the `heading` a link when provided.                                                                                                                                  |
| linkAriaLabel           | string           | no          | `aria-label` for the heading link. Use only if the visible text is not clear.                                                                                              |
| headingLevel            | number           | conditional | Deprecated. Use `heading.level` instead. Will be removed in v6.0.0.                                                                                                        |
| titleClasses            | string           | no          | Deprecated. Use `heading.classes` instead. Will be removed in v6.0.0.                                                                                                      |
| containerClasses        | string           | no          | Classes for the inner container.                                                                                                                                           |
| description             | string or object | conditional | Description below the title. Pass a string for plain text, or an object with `text`, `html` or `classes`. Plain text is wrapped in a paragraph; HTML is inserted directly. |
| description.text        | string           | conditional | Plain text description. Ignored if `description.html` is given.                                                                                                            |
| description.html        | string           | conditional | HTML description (allows markup). Overrides `description.text`.                                                                                                            |
| description.classes     | string           | no          | Classes for the description paragraph when `description.text` is used.                                                                                                     |
| descriptionHtml         | string           | no          | Deprecated. Use `description.html` instead. Ignored if `description` is set.                                                                                               |
| descriptionClasses      | string           | no          | Deprecated. Use `description.classes` instead.                                                                                                                             |
| aboveContent.text       | string           | no          | Text shown above the title. Ignored if `aboveContent.html` is given.                                                                                                       |
| aboveContent.html       | string           | no          | HTML shown above the title (for example a tag). Overrides `aboveContent.text`.                                                                                             |
| footer.text             | string           | no          | Text shown in the footer. Ignored if `footer.html` is given.                                                                                                               |
| footer.html             | string           | no          | HTML shown in the footer. Overrides `footer.text`.                                                                                                                         |
| img{}.src               | string           | conditional | Image URL. Adds an image section when present.                                                                                                                             |
| img{}.alt               | string           | no          | Image alt text. Leave empty only if purely decorative.                                                                                                                     |
| badgeLarge{}.count      | number           | conditional | Number for the large badge. Badge appears only when `count > 0`.                                                                                                           |
| badgeLarge{}.label      | string           | yes         | Visually hidden text read after the number.                                                                                                                                |
| badgeLarge{}.id         | string           | no          | ID attribute for the badge.                                                                                                                                                |
| badgeLarge{}.classes    | string           | no          | Classes for the badge.                                                                                                                                                     |
| badgeLarge{}.attributes | object           | no          | HTML attributes for the badge (e.g. `data-*`, `aria-*`).                                                                                                                   |
| id                      | string           | no          | ID for the card.                                                                                                                                                           |
| classes                 | string           | no          | Classes for the card.                                                                                                                                                      |
| attributes              | object           | no          | HTML attributes for the card (e.g. `data-*`, `aria-*`).                                                                                                                    |
