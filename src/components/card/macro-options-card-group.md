| Name                           | Type             | Required    | Description                                                                                                                                                                   |
| ------------------------------ | ---------------- | ----------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| heading                        | string or object | conditional | Card group heading. Pass a string or an object with `text`, `html`, `level` or `classes`.                                                                                     |
| heading.text                   | string           | conditional | Plain text heading. Ignored if `heading.html` is given.                                                                                                                       |
| heading.html                   | string           | conditional | HTML heading (allows markup). Overrides `heading.text` and `heading.level`.                                                                                                   |
| headingHtml                    | string           | conditional | Deprecated. Use `heading.html` instead. Will be removed in v6.0.0.                                                                                                            |
| heading.level                  | number           | conditional | Heading level (2–6) for the group `heading`. Defaults to 2 when not set. Ignored if `heading.html` is given.                                                                  |
| heading.classes                | string           | no          | Classes for the group heading element.                                                                                                                                        |
| headingLevel                   | number           | conditional | Deprecated. Use `heading.level` instead. Will be removed in v6.0.0.                                                                                                           |
| description                    | string or object | conditional | Description shown under the group heading. Pass a string for plain text, or an object with `text` or `html`. Plain text is wrapped in a paragraph; HTML is inserted directly. |
| description.text               | string           | conditional | Plain text description. Ignored if `description.html` is given.                                                                                                               |
| description.html               | string           | conditional | HTML description (allows markup). Overrides `description.text`.                                                                                                               |
| descriptionHtml                | string           | no          | Deprecated. Use `description.html` instead. Ignored if `description` is set.                                                                                                  |
| stacked                        | boolean          | no          | Adds `nhsapp-cards--stacked` class to card group.                                                                                                                             |
| isListItem                     | boolean          | no          | If true (default) wrapper is `<ul>` with each card as `<li>`. If false uses `<div>` wrappers.                                                                                 |
| id                             | string           | no          | ID for the card group.                                                                                                                                                        |
| classes                        | string           | no          | Classes for the card group.                                                                                                                                                   |
| attributes                     | object           | no          | HTML attributes for the card group (data-_ or aria-_).                                                                                                                        |
| cards                          | array            | yes         | Array of card objects.                                                                                                                                                        |
| cards[]heading                 | string or object | conditional | Card heading. Pass a string or an object with `text`, `html`, `level`, `classes`, `size` or `id`. Renders as a link, heading or paragraph.                                    |
| cards[]heading.text            | string           | conditional | Plain text heading. Ignored if `heading.html` is given.                                                                                                                       |
| cards[]heading.html            | string           | conditional | HTML heading (allows markup). Overrides `heading.text`.                                                                                                                       |
| cards[]heading.level           | number           | conditional | Heading level (2–6) used only when there is no `href`. If not set (and no `href`) the heading is a paragraph.                                                                 |
| cards[]heading.classes         | string           | no          | Classes for the heading element.                                                                                                                                              |
| cards[]heading.size            | string           | no          | Size of the heading: `xxs`, `xs`, `s`, `m`, `l` or `xl`. Adds the matching `nhsuk-heading-*` class.                                                                           |
| cards[]heading.id              | string           | no          | ID for the heading element.                                                                                                                                                   |
| cards[]headingHtml             | string           | conditional | Deprecated. Use `cards[]heading.html` instead. Will be removed in v6.0.0.                                                                                                     |
| cards[]title                   | string or object | conditional | Deprecated. Use `cards[]heading` instead. Will be removed in v6.0.0.                                                                                                          |
| cards[]titleHtml               | string           | conditional | Deprecated. Use `cards[]heading.html` instead. Will be removed in v6.0.0.                                                                                                     |
| cards[]href                    | string           | conditional | Makes the `heading` a link when provided.                                                                                                                                     |
| cards[]linkAriaLabel           | string           | no          | `aria-label` for the heading link. Use only if the visible text is not clear.                                                                                                 |
| cards[]headingLevel            | number           | conditional | Deprecated. Use `cards[]heading.level` instead. Will be removed in v6.0.0.                                                                                                    |
| cards[]titleClasses            | string           | no          | Deprecated. Use `cards[]heading.classes` instead. Will be removed in v6.0.0.                                                                                                  |
| cards[]containerClasses        | string           | no          | Classes for the inner container.                                                                                                                                              |
| cards[]description             | string or object | conditional | Description below the title. Pass a string for plain text, or an object with `text`, `html` or `classes`. Plain text is wrapped in a paragraph; HTML is inserted directly.    |
| cards[]description.text        | string           | conditional | Plain text description. Ignored if `description.html` is given.                                                                                                               |
| cards[]description.html        | string           | conditional | HTML description (allows markup). Overrides `description.text`.                                                                                                               |
| cards[]description.classes     | string           | no          | Classes for the description paragraph when `description.text` is used.                                                                                                        |
| cards[]descriptionHtml         | string           | no          | Deprecated. Use `description.html` instead. Ignored if `description` is set.                                                                                                  |
| cards[]descriptionClasses      | string           | no          | Deprecated. Use `description.classes` instead.                                                                                                                                |
| cards[]aboveContent.text       | string           | no          | Text shown above the title. Ignored if `aboveContent.html` is given.                                                                                                          |
| cards[]aboveContent.html       | string           | no          | HTML shown above the title (for example a tag). Overrides `aboveContent.text`.                                                                                                |
| cards[]footer.text             | string           | no          | Text shown in the footer. Ignored if `footer.html` is given.                                                                                                                  |
| cards[]footer.html             | string           | no          | HTML shown in the footer. Overrides `footer.text`.                                                                                                                            |
| cards[]img{}.src               | string           | conditional | Image URL. Adds an image section when present.                                                                                                                                |
| cards[]img{}.alt               | string           | no          | Image alt text. Leave empty only if purely decorative.                                                                                                                        |
| cards[]badgeLarge{}.count      | number           | conditional | Number for the large badge. Badge appears only when `count > 0`.                                                                                                              |
| cards[]badgeLarge{}.label      | string           | yes         | Visually hidden text read after the number.                                                                                                                                   |
| cards[]badgeLarge{}.id         | string           | no          | ID attribute for the badge.                                                                                                                                                   |
| cards[]badgeLarge{}.classes    | string           | no          | Classes for the badge.                                                                                                                                                        |
| cards[]badgeLarge{}.attributes | object           | no          | HTML attributes for the badge (e.g. `data-*`, `aria-*`).                                                                                                                      |
| cards[]id                      | string           | no          | ID for the card.                                                                                                                                                              |
| cards[]classes                 | string           | no          | Classes for the card.                                                                                                                                                         |
| cards[]attributes              | object           | no          | HTML attributes for the card (e.g. `data-*`, `aria-*`).                                                                                                                       |
