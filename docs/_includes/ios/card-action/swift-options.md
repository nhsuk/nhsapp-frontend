**Card action styles**

| Option     | Description                                                                |
| ---------- | -------------------------------------------------------------------------- |
| `.primary` | Body text with a chevron. The default for rows in a group                  |
| `.plain`   | Blue text with no chevron, for rows in a secondary group                   |
| `.reverse` | White text with a bold title on a blue card, for a standout row on its own |

**Card action group styles**

| Option       | Description                                                                     |
| ------------ | ------------------------------------------------------------------------------- |
| `.primary`   | A white card with no border. The default                                        |
| `.secondary` | A clear card with a 2pt border, for less emphasis; its rows use the plain style |
