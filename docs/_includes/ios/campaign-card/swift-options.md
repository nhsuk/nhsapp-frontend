| Option              | Description                                                                                                                                                                                   |
| ------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `image`             | The campaign photograph, from your app's asset catalogue. The image is decorative and hidden from VoiceOver                                                                                   |
| `title`             | The heading, shown in bold                                                                                                                                                                    |
| `subtitle`          | The body text, shown below the heading                                                                                                                                                        |
| `accessibilityHint` | Optional. A short description of what happens on tap, read out by VoiceOver after the card's text. Only set this if the heading and body text do not already make the result of tapping clear |
| `action`            | The closure to run when the card is tapped                                                                                                                                                    |
