The NHS App web app is built using the [NHS digital service manual design system](https://service-manual.nhs.uk/design-system), with additional components and styles for the NHS App.

The web app must meet [WCAG 2.2 AA](https://www.w3.org/TR/WCAG22/), the minimum standard required by law for public sector digital services. The [NHS App accessibility statement](https://www.nhs.uk/nhs-app/about/privacy-legal-information/nhs-app-accessibility-statement/) explains how accessible the app is, and any known issues.

## Using the NHS App design system

Each component and style in the NHS App design system includes accessibility guidance. Follow this guidance when using them in your service.

Read the [NHS digital service manual guidance on accessibility](https://service-manual.nhs.uk/accessibility).

## Integrated services

Services that integrate with the NHS App are not covered by the NHS App accessibility statement. Read about [accessibility for integrated services](/accessibility/integrated-services/).
